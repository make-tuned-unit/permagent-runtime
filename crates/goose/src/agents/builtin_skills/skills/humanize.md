name: humanize
description: Draft or rewrite user-facing marketing and outbound copy (social posts, outreach messages, value propositions, launch content) so it reads like a sharp human wrote it, not a chatbot, with no AI tells. Apply whenever you draft external copy the user will publish or send to another person.
---

Use this skill whenever you draft copy that leaves the app and reaches another
human: social posts, outreach and cold messages, value propositions, launch
announcements, landing-page lines. The goal is copy that reads like a sharp
person wrote it in one sitting, not a chatbot filling a template. Run every
draft through the rules below before you hand it back.

This governs drafted external copy only. It does not change how you talk in
normal conversation, and it never edits the app's own interface text.

## Strip the AI tells

1. **No em-dashes.** This is the single biggest giveaway that a machine wrote
   the text. Use a period or a comma instead. If a sentence leans on an
   em-dash, it is usually two sentences.
2. **No throat-clearing openers.** Cut "I hope this finds you well", "In
   today's fast-paced world", "In an era of", "As you know". Delete the windup
   and start on the actual point.
3. **No hype adjectives.** Ban "seamless", "leverage", "unlock", "revolutionary",
   "game-changing", "cutting-edge", "supercharge", "elevate", "transform".
   These words carry no information and read as ad copy. Say the concrete thing
   the product does instead.

## Write like a person

4. **Lead with the point.** The first sentence carries the message. Do not warm
   up to it. If someone reads only line one, they should get the payload.
5. **Be specific, cite something real.** A concrete detail, number, name, or
   example beats a generic claim every time. "Cuts a 20-minute task to 2" lands;
   "boosts productivity" does not.
6. **Short, concrete sentences.** Prefer plain words and one idea per sentence
   over long, abstract, subordinate-clause pileups. Read it aloud. If you run
   out of breath, split it.
7. **One person to one person.** Write as if you are talking to a single reader
   you respect, not broadcasting to a market. Contractions are fine. A little
   personality is better than polished nothing.

## Before you hand it back

Re-read the draft and check: zero em-dashes, no throat-clearing first line, no
banned hype words, the point is in sentence one, at least one specific concrete
detail, sentences you can say in one breath. Fix anything that fails, then
deliver.
