# Permagent Runtime

Fork of Goose (Apache 2.0, AAIF/Linux Foundation) evolved into the Permagent agent OS.

**Stack:** Rust execution engine + Tauri shell + MCP toolsheds + Spectral memory (SQLite temporal KG) + Command Center (Next.js on localhost)

**Phase 1:** macOS only, web-based Command Center, repetition-only auto-skills detection, Gmail + Slack integrations, no Mesh sharing, no .dmg.
