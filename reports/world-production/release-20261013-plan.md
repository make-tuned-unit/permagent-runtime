## Findings

**Sidecar signing path.** `copy-sidecar.sh` signs only ad hoc (`codesign --force --sign -`, errors swallowed by `|| true`) after `install_name_tool` edits, on the copies in `src-tauri/binaries/`. It therefore re-signs the stale-signature dylibs itself, and the `isolated_daemon.py sign-libs` fix is not needed for the bundle (only for the dylibs next to `release/permagentd`). `copy-cli.sh` leaves cargo's ad hoc signature. `tauri.conf.json` has `signingIdentity: null`, so the identity comes only from the `APPLE_SIGNING_IDENTITY` environment variable. Tauri re-signs the main exe, `externalBin` (`binaries/permagentd`, `binaries/permagent` -> `Contents/MacOS/`) and `macOS.frameworks` (the two dylibs -> `Contents/Frameworks/`) with that identity and `Entitlements.plist`. I could not confirm from source whether Tauri signs `bundle.resources` Mach-O files (`mcp-runtime/node` and native addons under `node_modules`, `permagent-audiocap`), because no tauri-bundler source is on this machine. Step 3 therefore audits every Mach-O in the bundle and, only for offenders, re-signs them inner-first with `--options runtime --timestamp --entitlements Entitlements.plist` and then re-signs the bundle. Step 4 independently requires all to be Developer ID signed.

**Bundled daemon sha cannot equal a73a4ac4.** `copy-sidecar.sh` adds an rpath (`install_name_tool`) and re-signs, and Tauri signs again, so the bundled file's whole-file sha differs. Step 4 compares `__TEXT,__text` hashes against `release/permagentd` instead, and the manifest records both. Same for the CLI.

**build-audiocap.sh would compile.** It runs `swiftc -O` on `main.swift` into the tracked file `src-tauri/audiocap/permagent-audiocap` and ad hoc signs it. Not run. Step 1 copies the reviewed helper (03ffdfa5) over that tracked path, which makes the tree show one modified file (committed binary is 4f5f0dab, not the reviewed one). Step 0 tolerates that file only if it equals the reviewed sha. Restore afterwards with `git checkout -- ui/desktop/src-tauri/audiocap/permagent-audiocap` (not done by the script).

**provenance-check.sh is hard-wired to `/Users/j/Documents/dev/permagent-runtime`** (`MAIN=`): `pre` reports that checkout's HEAD and `post` greps that checkout's `dist`. The script runs a copy with `MAIN` rewritten to this lane (not modifying the original). Its marker lists end at the 09-25 release and have no World markers; MISSING lines are advisory, not gating.

**verify_native_review.mjs cannot check a release bundle** (hard-wired to `debug/permagent-app`, debug codegen dirs, review identifiers). Step 4 writes `logs/verify_release_embedded_20261013.mjs` with the same method on release paths (`release/build/permagent-app-*/out/tauri-codegen-assets`, brotli-decode, keep only assets whose bytes are inside the bundled binary, require every non-HTML dist file and the vista manifest to match byte for byte, plus the two markers).
