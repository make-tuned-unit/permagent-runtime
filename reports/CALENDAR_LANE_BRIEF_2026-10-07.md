## Build
1. **Data:** one `useCalendarEvents(range)` hook that returns events for an arbitrary date range from the best source available: the Tauri EventKit bridge when present (extend `calendar.rs` to take `start`/`end` ISO timestamps and return id, title, calendar name + colour, start/end, all-day flag, location, attendees count, url; keep the existing command working), else the daemon route, else an honest "connect Apple Calendar in the desktop app" state. Cache per range; refresh on focus and every 5 min; never block render.
2. **Card:** `CalendarCard` becomes a real calendar: a header with the current period title, Today, ‹ ›, and a segmented control Day · Week · Month (persist the choice per layout in localStorage via the existing card-settings pattern if one exists, else the card's own key); Month = 6-week grid with up to 3 event chips per day and "+N"; Week = 7 columns × hours with all-day row on top, now-line, overlapping events laid side by side; Day = hourly timeline with the now-line and the event list beside it. Clicking an event opens a detail popover (title, when, where, calendar, attendees, open-in-Calendar link via the existing shell-open helper). Keyboard: ←/→ move period, T today, D/W/M switch views; focus order sane; `prefers-reduced-motion` honoured for view transitions.
3. **Next up:** a strip at the top of the card ("Next: Standup · in 42 min · Work") with a live countdown (minute precision), plus the next 3 events in the compact card size. When the card is in a compact size (the smallest preset), show only "Next up" + today's list; the full calendar needs the medium/large sizes — declare the size presets in `cards/registry.ts` so the Layouts gallery offers it correctly.
4. **Design:** tokens only (`styles/tokens.ts`), theme colours from `useTheme()`, `Button`/`Tooltip`/`Chip` primitives; calendar colours from the source calendar mapped through the theme (no raw hex); both themes; dense but legible at 1244 and 1440 wide; empty states ("No events this week", "Calendar access not granted → Grant" using the existing `CalendarAccessPanel`).
5. **Tests:** hook (range queries, source fallback order, cache), month-grid layout (6 weeks, overflow +N), week overlap layout, next-up countdown, keyboard shortcuts; the convention scanners (spaceScale, rawButton, backdropFilter) must stay green.
