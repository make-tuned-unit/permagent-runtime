# First-run setup — design (lane wq/wizard, 2026-10-07)

Six steps, two of them optional, one decision per screen. Shell: header (`Back` · `Step N of 6 · <Label>` + 6 labelled segments, aria-live) / scrolling body (`margin:auto` centring, never clips) / pinned footer (secondary left, primary right). Each step is a `<form>`: Enter = primary when valid, Escape = Back (step > 1), focus moves to the step's first field (else its heading) on entry. Only the active step is mounted; shared choices live in the shell and in a localStorage draft (`permagent-wizard-draft-v1`: step, persona, first message, return-to-review flag). Nothing auto-advances. Re-opening resumes at the saved step; the review re-reads what the backend actually holds.

| # | Label | Collects | Skip / default | Validation |
|---|---|---|---|---|
| 1 | Welcome | nothing | — | — |
| 2 | Model | how the agent thinks: hosted provider + key, local (Ollama) + model, or "Decide later" | no choice pre-selected; "Decide later" is an explicit option | hosted: key saved → provider set → live check (lists models with the key). Continue only after "Key works", or "Couldn't confirm live" with the reason. Auth rejection blocks. Local: Continue only with an installed model selected. |
| 3 | Agent | name, one tone chip | name blank → server default persona name ("Aria"); tone "Balanced" | name ≤ 40 chars; server rejects an empty name |
| 4 | Code folders (optional) | folders that hold your code | "I don't write code" writes `[]` (clears a stale list) | typed paths checked before they are added |
| 5 | Extras (optional) | web search key; local memory model | both off; "Skip" | search: save + live probe; memory model: consent → start Ollama / download with progress + Cancel |
| 6 | Review | optional first message | — | rows: Model · Agent · Code folders · Web search · Memory model, each with Change (returns here) → **Start Permagent** |

## Copy
1. **Welcome to Permagent** — "An agent that works on your Mac: it chats, runs tasks in terminals and the browser, and remembers what matters to you. Setup takes about two minutes." Panel **Stays on this Mac**: "Your memory, chats and settings live in `~/.permagent`." / "API keys go in the macOS keychain (or your password manager)." / "Usage analytics are off unless you turn them on in Settings." Panel **Leaves this Mac**: "Your messages go to the model provider you choose — and only to it. Pick a local model and nothing leaves at all." / "Web search sends queries to the search service you connect." Primary **Get started**.
2. **Choose a model** — "Permagent needs a language model to think with. Use a hosted provider with an API key, or run one on this Mac." Options: **Hosted provider** ("Best quality. Needs an API key.") / **On this Mac** ("Private and free to run. Needs Ollama and a few GB of disk.") / **Decide later** ("Look around first. The agent can't reply until a model is connected."). Hosted: provider list (from the daemon registry, alphabetical, key-based only; others → "More providers, sign-ins and custom endpoints are in Settings → Models"), key field, "macOS may ask once to let Permagent use your keychain — choose Always Allow." Help: the provider's own setup steps + key page link. Results: "Key works · <model>" / "The provider rejected this key: <reason>" / "Saved, but couldn't confirm it live: <reason>". Local: "Ollama isn't running" (Start Ollama / Get Ollama ↗), installed models as a list, or "Download <model> (≈N GB)" sized to this Mac's memory, with progress + Cancel.
3. **Name your agent** — "Pick a name and a tone. You can change both, and its voice, in Settings." Tone chips: Balanced / Direct / Warm / Curious. Preview: "It will greet you: '<greeting>'".
4. **Where is your code?** — "Optional. Tell your agent which folders hold your projects so it works on the right ones." Primary: "Use N folders" / footer secondary "I don't write code".
5. **Extras** — "Both optional, both can be added later in Settings." Cards: **Web search** ("Lets your agent look things up. Needs a free key from a search service; queries go to that service.") / **Local memory model** ("A small model on this Mac that tidies and links your memories overnight. Nothing leaves your Mac. Downloads ≈N GB.") — nothing starts or downloads until the person presses the button.
6. **Ready when you are** — summary rows; if no model: "No model is connected, so your agent can't reply yet. Add one any time in Settings → Models." Optional "First message" field ("Anything you want to start with?"). Primary **Start Permagent**. Save failure banner: Retry / Continue anyway (says setup may reappear).

## Boot
One connect owner (BootScreen) with a stable callback, shared classifier (`app` / `wizard` / `malformed`), plain copy ("Permagent's background service"), never "daemon".
